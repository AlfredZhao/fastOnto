# fastOnto 平台测试：用 LinkML 回答四个问题

> 目的：以 SH 只读销售数据验证 fastOnto 的最小闭环。本文既是演示手册，也是验收清单。
>
> 基本原则：**LinkML 是本体模型主源；SH 仍是业务数据主源；LLM 负责理解与表述，不生成或执行 SQL。**

## 测试前准备

1. 数据库迁移已执行至当前版本，后端和 HTTPS Gateway 已重启。
2. 登录平台；进入“业务数据源”，确认 SH 白名单能预览 `SALES`、`PRODUCTS`、`CUSTOMERS`、`TIMES`、`CHANNELS`、`PROMOTIONS`。
3. 如需验证 AI 路由和 AI 解读，在“LLM 配置”中已有一个可用默认模型；没有默认模型时，平台应降级为规则路由，仍不允许生成 SQL。
4. 本手册将 `AMOUNT_SOLD` 作为**人民币销售额展示口径**。如果真实源数据不是人民币，必须新建经审核的换算指标，不能在问答时临时换算。

---

# 01. 如何构建本体

## 回答

本平台以 **LinkML YAML** 构建本体，图形关系图用于阅读、检查和布局，不是第二份可编辑模型。

构建过程是：

```text
业务语言 / 数据字典 / 文档
→ LinkML 类、属性、关系、类型、约束
→ 平台结构校验
→ 保存模型版本
→ 本体关系图阅读与调整
```

对于 SH 销售域，建议至少建立以下概念：

```text
Customer、Product、Channel、Promotion、Country、SalesRecord
```

其中 `SalesRecord` 是销售事实概念；由于 `SH.SALES` 没有永久业务主键，当前不把它伪造成拥有永久 IRI 的明细实体。

## 平台测试步骤

1. 进入 **模型工作台**。
2. 点击 **新建模型**，选择“销售”模板；也可导入 `models/sales.yaml`。
3. 点击 **校验模型**。
4. 验证检查器中至少出现 `Customer`、`Product`、`Channel`、`Promotion`、`SalesRecord`。
5. 打开 **关系** 页签，验证存在：

   ```text
   SalesRecord → Customer
   SalesRecord → Product
   SalesRecord → Channel
   SalesRecord → Promotion
   ```

6. 在下方 **本体关系图** 拖动一个类卡片，刷新页面，验证布局仍保留；点击“恢复默认”，验证布局可还原。
7. 点击 **保存版本**，记录模型名称和版本号，例如“中文体育用品销售本体 v3”。

## 通过标准

- LinkML 校验成功；
- 类、属性和对象关系可在检查器及关系图中一致显示；
- 保存后模型可从“已保存的模型”中重新加载；
- 拖动关系图不改变 LinkML 源码或 SH 数据。

# 02. 本体需要定义什么

## 回答

本体不是把数据库列改名，而是定义业务对象及其可解释、可计算的语义。至少需要四层内容：

| 层次 | LinkML / 平台内容 | SH 销售示例 |
|---|---|---|
| 对象 | 类、标识、说明 | Customer、Product、SalesRecord |
| 属性 | 数据属性、类型、必填性 | 产品类别、标价、销售日期、金额、数量 |
| 关系 | 对象属性及值域 | SalesRecord 的客户、产品、渠道、促销 |
| 分析语义 | 指标、维度、时间范围、场景、展示规则 | 销售额、销量、按月趋势、商品 Top N |

LinkML 主要负责前三层；平台的治理与受控分析能力承载第四层。

当前 SH MVP 的受控原子指标为：

```text
销售额（人民币） = SUM(SH.SALES.AMOUNT_SOLD)
销售数量 = SUM(SH.SALES.QUANTITY_SOLD)
```

可分析维度包括月份、商品、产品类别、客户、渠道、促销。客户姓名显示顺序属于**维度展示规则**，不属于指标口径。

## 平台测试步骤

1. 在模型工作台选中 `SalesRecord`，确认：
   - `sale_date` 是日期；
   - `amount` 是金额；
   - `quantity` 是数量；
   - 客户、产品、渠道、促销是对象关系，而非普通字符串。
2. 打开 **业务域治理**：
   - 新建业务域“销售分析”；
   - 新建本体“中文体育用品销售本体”；
   - 关联前一步保存的 LinkML 模型版本。
3. 在 **指标问答** 的“客户展示规则”中选择“姓在前，名在后”，分隔符留空并保存。
4. 在自然语言框输入：

   ```text
   销售额最高的10个客户是什么？
   ```

5. 验证结果显示十条以内客户聚合结果，客户名称按“姓在前、名在后”展示。

## 通过标准

- 对象、属性和关系在 LinkML 中可追溯；
- 指标口径不允许由问题临时改变；
- 展示规则改变不应改变销售额、销量或排名计算；
- “利润最高的商品是什么？”应被拒绝，因为当前未定义利润指标。

# 03. 如何映射数据

## 回答

映射把 LinkML 对象和只读源字段建立明确对应关系；它不复制 SH 数据，也不开放任意 Join SQL。

单表映射示例：

| LinkML 类 | SH 表 | 主体字段 | 典型属性 |
|---|---|---|---|
| Product | `SH.PRODUCTS` | `PROD_ID` | 名称、类别、标价 |
| Customer | `SH.CUSTOMERS` | `CUST_ID` | 姓名、城市、国家 |
| Channel | `SH.CHANNELS` | `CHANNEL_ID` | 渠道名称、类别 |
| Promotion | `SH.PROMOTIONS` | `PROMO_ID` | 活动名称、开始/结束日期 |

分析中允许的多表关系是服务端审阅过的键关联，不是用户填写 SQL：

```text
SALES.PROD_ID     → PRODUCTS.PROD_ID
SALES.CUST_ID     → CUSTOMERS.CUST_ID
SALES.CHANNEL_ID  → CHANNELS.CHANNEL_ID
SALES.PROMO_ID    → PROMOTIONS.PROMO_ID
SALES.TIME_ID     → TIMES.TIME_ID
```

## 平台测试步骤

1. 在 **业务域治理** 中，确保本体已关联一个已保存 LinkML 版本。
2. 点击“新建字段映射”。
3. 选择 `SH.PRODUCTS`：
   - 选择 `Product`；
   - 主体字段选择 `PROD_ID`；
   - 配置产品名称、类别、标价等标量属性；
   - 可先点击自动匹配，再人工核对。
4. 重复配置 `Customer` 与 `SH.CUSTOMERS`。
5. 点击映射校验，检查源字段、模型属性、主体模板是否匹配。
6. 在“业务数据源”中预览对应 SH 表，核对字段名与映射选择一致。

## 通过标准

- 映射仅引用白名单 SH 表与字段；
- 主体字段使用真实稳定主键；
- 平台不允许在界面提交 Join、SQL、SPARQL、脚本或表达式；
- `SalesRecord` 不应以五维组合键、哈希、`ROWID` 等方式伪造永久业务身份；
- 关系型分析 Join 仅使用上述受控关联。

# 04. 如何使用本体

## 回答

使用本体的目标不是“直接让 LLM 问库”，而是让自然语言稳定地落到：

```text
本体对象与关系
→ 已定义指标与维度
→ 规范化时间范围
→ 受控查询模板
→ 结果表、图表、口径与追溯
```

当前平台提供两种清晰模式：

| 模式 | 用途 | 结果性质 |
|---|---|---|
| 正式指标问答 | 已有销售额/销量等定义 | 固定口径、可复现、可追溯 |
| 受限探索 | 尚未形成正式口径的问题探索 | 仅限审阅模板，明确标注为非正式口径 |

LLM 只能识别已有场景、指标、维度、时间及 Top N；服务端会重新校验。LLM 不生成 SQL，也不决定指标公式。

## 平台测试步骤

### A. 趋势与图表

1. 打开 **指标问答**，选择“正式指标问答”。
2. 输入：

   ```text
   每月销售额趋势怎样？
   ```

3. 预期：
   - 命中销售额与月份维度；
   - 返回折线图及表格；
   - 月份按时间正序，不按销售额大小排序；
   - 可切换柱形图或环图；表格仍保留。

### B. Top N 排名

1. 输入：

   ```text
   销售额最高的10个商品是什么？
   ```

2. 预期：
   - `Top N = 10`；
   - 返回最多十行；
   - 默认显示横向柱形图；
   - 追溯显示销售额口径、参数和读取 SH 表。

### C. 相对时间与多指标

1. 输入：

   ```text
   本月销售额和销量是多少？
   ```

2. 预期：
   - 同时返回销售额与销量两组结果；
   - 二者使用相同的绝对时间范围；
   - 在当前 `Asia/Shanghai` 时间下，“本月”会被追溯为 `[月初, 下月月初)`；
   - 若 SH 没有该时期数据，应显示空结果，不得回退为全量数据。

### D. 未定义指标拒答

1. 输入：

   ```text
   利润最高的商品是什么？
   ```

2. 预期：拒绝执行，并说明当前没有已定义利润口径。

## 通过标准

- 每次结果均能看到指标、时间、维度、返回条数、数据表和执行模式；
- 图表由同一受控结果集生成，表格仍是核对依据；
- “本月”等相对时间转化为绝对时间范围；
- 没有定义的指标不猜测、不查库；
- 受限探索不得被误标为正式经营指标。

---

## 当前边界与下一步验收项

当前运行模板仍是 SH MVP 的审阅代码模板。后续验收必须补齐“运行契约”：每次问答都锁定并展示**本体 ID/版本、映射版本、指标版本、场景版本及模板版本**。在此之前，平台已经能验证受控问答机制，但尚未完全实现“用户配置的指标资产发布后自动驱动运行”。
