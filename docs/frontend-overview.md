# 前端基础版

## 设计与结构

继承 trustedKnowledge 的 ink/mint 工作台视觉、8px 面板和紧凑工具栏，不复制其单体 App.tsx。使用语义 CSS 颜色变量统一深浅主题，不使用整页选择器事后反色。

- `AuthGate.tsx`：登录与会话恢复；首次强制改密前不挂载工作台、不请求业务数据。
- `PasswordForm.tsx`：首次改密与账户安全页共用。
- `App.tsx`：应用壳、路由、系统连接检查、退出和账户安全。
- `useWorkspace.ts`：独立草稿与模型保存状态，跨路由保留，不持久化正文。
- `views/ModelWorkspace.tsx`：资源树 / YAML / 属性和关系列表。
- `components/ModelCreator.tsx`：模板、文件解析预览、候选审核及独立草稿生成；不把原文件写入浏览器持久存储。
- `views/SourceWorkspace.tsx`：固定源清单与只读分页表格。
- `components/Dialog.tsx`：原生 dialog 管理焦点与 Esc；不使用浏览器 confirm。

## 交互边界

校验只更新“校验快照”，不改动草稿。编辑后旧报告显式标记过期。保存记录提交时的源码；请求期间继续编辑的内容不能被标记为已保存。打开另一个模型前需要确认放弃草稿。

新建/导入重置平台记录 ID；另存为新模型使用空 ID 和版本零，保留原模型历史。工作台挂载在路由切换之外，离开时隐藏以保留候选编辑；离开期间完成的请求不能弹出不可见确认框。模板/生成结果应用前检查最新工作台状态，避免旧闭包覆盖后续修改。关闭向导取消请求、使迟到响应失效；退出登录卸载全部工作台状态。

上传支持 XLSX/DOCX/Markdown/TXT/YAML，2 MiB 上限。文档提取是本地规则候选而非 AI 理解；勾选审核后才能生成 LinkML，修改候选会撤销勾选。文件名、文档内容及证据只作为纯文本呈现；HTTP 风险、无候选、解析失败及容量限制有明确提示。详见 `document-import.md`。

业务数据源切换取消旧请求，并按请求编号核对响应；不把旧表数据显示在新表标题下。数据清单是配置，不是假装已连通的数据库元数据。

主题在 React 挂载前恢复；只接受 `dark` / `light` 两个值。没有 Service Worker 或业务数据缓存；密码、会话令牌、CSRF token 不写入 localStorage/sessionStorage。会话令牌只在 HttpOnly Cookie 中，CSRF token 仅保存在当前内存。

默认 `npm run dev` 为用户选择的临时外部 HTTP 模式，监听 0.0.0.0:8025；`npm run dev:local` 仅本机。公开访问不是生产部署承诺，页面明确提示 HTTP 风险。所有业务 API 已独立认证，不能靠隐藏菜单保护数据。

## 布局验收

桌面为应用侧栏加建模三栏；中等宽度检查器换到下一行；手机按资源、源码、检查器排列。所有操作栏可换行，表格和代码仅局部横向滚动，长 URI 断行，输入字号避免手机自动缩放。

Playwright 覆盖 1440×1000、375×812、320×740、812×375 的深浅主题，外加空/失败/异步/对话框用例。截图人工检查过桌面深色与手机浅色。
